# 한 입 크기로 잘라먹는 실전 프로젝트 - SNS편

### 강의 소개
강의 제목 : 한 입 크기로 잘라먹는 실전 프로젝트 - SNS편
강의 내용 : React 기반의 SNS 웹 사이트 개발
해당 강의에서 사용한 기술 스택 : Vite, Vercel, Zustand, TanstackQuery, Supabase, ShadcnUI, TailwindCss
수강 기간 : 2025년 10월 23일 ~ 2025년 12월 1일(완강)

---

### 배포
#### [한입 로그](https://onebite-log-five.vercel.app/)

### 기존 강의에서 구현한 기능
> 1. 회원가입 기능(이메일 또는 OAuth-Git 아이디로 회원가입)
> 2. 로그인 및 로그아웃 기능
> 3. 비밀번호 재설정 기능
> 4. 포스트 조회, 추가, 수정, 삭제 기능
> 5. 포스트 무한 스크롤 기능
> 6. 포스트 좋아요 기능 
> 7. 포스트 댓글 추가, 수정, 삭제 기능
> 8. 포스트 댓글의 답댓글 및 무한 중첩 댓글 기능
> 9. 테마 기능
